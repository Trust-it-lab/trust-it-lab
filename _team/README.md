# How to add or edit a team member

Each person is one file in this folder. Only `name` and `order` are required;
every other line is optional and simply does not appear if left out.

```
---
name: "Their Name"
order: 7
role: "PhD Student, Purdue University Northwest"
interests: "Topic one, Topic two"
bio: "One or two sentences about their research."
scholar: "https://scholar.google.com/citations?user=..."
linkedin: "https://www.linkedin.com/in/..."
github: "https://github.com/..."
website: "https://..."
email: "name@pnw.edu"
---
```

**To add someone:** copy any file here, rename it (for example `07-jane-doe.md`),
and fill in the lines.

**To remove someone:** delete their file.

`order` decides where they appear — smaller numbers come first.
